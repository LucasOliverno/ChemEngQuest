# 🧪 ChemQuest — Minha Jornada Gamificada

> App pessoal para gamificar os 12 meses do roadmap **"Chemical Engineer → AI-Powered Freelancer & Industrial Consultant"** e tornar o processo mais leve, visual e motivador.

---

## 🎯 O Que É

Um app web simples (single-page) que roda local ou no navegador, feito **só pra mim**, para:

- ✅ Acompanhar meu progresso real nas 6 fases do roadmap
- 🔥 Manter um streak diário de estudo (não quebrar a corrente!)
- 🏆 Desbloquear conquistas conforme completo atividades reais
- 📊 Visualizar meu avanço de forma satisfatória (barras, gráficos, animações)
- 💪 Sentir que estou evoluindo — transformar "estudar Darcy-Weisbach" em "ganhar 50 XP"

**Não é um MVP. Não é para lançar. É meu painel pessoal de motivação.**
